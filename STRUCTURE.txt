🎯 DEPLOYMENT FLOW
═════════════════════════════════════════════════════════════════════════════

1️⃣  CLONE ONCE
    git clone https://github.com/siva-narayana-1/ip_streamer.git
    cd ip_streamer

2️⃣  DEPLOY BACKEND
    sudo ./backend.sh
    - npm install in backend/
    - Create database
    - Start systemd service (port 3000)

3️⃣  DEPLOY FRONTEND
    sudo ./frontend.sh
    - npm install in frontend/
    - npm run build (creates frontend/dist/)
    - Copy to /srv/rtsp-viewer-frontend

4️⃣  SETUP NGINX
    sudo ./nginx_setup.sh streamtest.sivabio.in streamtest-api.sivabio.in
    - Create configs in /etc/nginx/sites-available/
    - Configure reverse proxy to port 3000
    - Configure WebSocket proxying

5️⃣  SSL CERTIFICATES
    sudo certbot --nginx -d streamtest.sivabio.in -d streamtest-api.sivabio.in

6️⃣  UPDATE & RESTART
    sudo nano backend/.env          (update CORS_ORIGIN)
    sudo systemctl restart rtsp-viewer-backend

═════════════════════════════════════════════════════════════════════════════
⚡ EACH SCRIPT IS INDEPENDENT
═════════════════════════════════════════════════════════════════════════════

backend.sh
  - Can run standalone
  - Assumes you're in project root (checks for backend/)
  - No cloning (uses existing repo)
  - Creates/starts systemd service
  - Output: Backend running on port 3000

frontend.sh
  - Can run standalone
  - Assumes you're in project root (checks for frontend/)
  - No cloning (uses existing repo)
  - Builds and deploys to /srv/rtsp-viewer-frontend
  - Output: Static files ready to serve

nginx_setup.sh
  - Can run standalone
  - Takes domain names as arguments
  - Assumes backend is running on :3000
  - Assumes frontend is deployed to /srv/rtsp-viewer-frontend
  - Creates nginx configs and reloads

monitor.sh (Optional)
  - Check service status anytime
  - No changes, just reads status
